# Honkai-Star-Rail---
以C/C++编写的模拟《崩坏：星穹铁道》里的来古士的权杖演算，不同的是不会有绝灭大君。永劫轮回共33550336次，但是在第八次后用户可以按回车健跳到最后一个轮回（但是由于白厄卡住了进程，所以可能会出现第八轮反复出现，等它跑完即可），文件所配备的BGM,MP4文件连同res文件夹找不到了，只有安装包跟C语言源码了
请新建文件夹并命名为“res”，然后将所有mp3文件和bitbug_favicon.ico拖进去，前者是程序运行BGM，后者是程序软件的图标。而后将res文件夹跟“翁法罗斯.exe”“conio”“heap”“locale”"math""runtime""stdio""VCRUNTIME140.dll"并行放置
由于本人技术原因，安装包暂时无法上传，故将源码以txt文本形式上传，如有需要可直接粘贴进任意C/C++编译器中进行编译运行，全程无额外插件
